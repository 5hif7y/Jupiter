 Build 69

New Features

The Jupiter System now supports HLSL shaders through DirectX Effect files.

The Jupiter System now supports wide character unicode fonts.

The Jupiter System now supports Maya 6.5, 7.0 and Max 7.0.

Documentation:

UPDATED  The Jupiter Development Guide provides introductory, overview, and quickstart information for programmers and artists using the Jupiter System.

UPDATED  The Jupiter API Reference provides documentation for classes and functions.

NEW  The Jupiter Engine Overview whitepaper outlines the basic Jupiter Engine Architecture.

NEW  The LipSync whitepaper explains the basic lipsync pipeline in Jupiter.

NEW  The Vertex Blending in Max whitepaper provides documentation on vertex blending using 3D Studio Max.

NEW  The Jupiter EffectShaders whitepaper provides documentation on the new EffectShader system in Jupiter.

Samples:

UPDATED  The \Samples\audio\sounds folder contains the updated Sounds sample. This sample now demonstrates 3D picking when pressing right-click on the mouse.

UPDATED  The \Samples\graphics\fonts folder contains the updated Fonts sample. This sample now demonstrates the use of the new LTFontParams class to set the TTF font style to italic. Also shows wide character unicode support.

NEW  The \Samples\graphics\effects folder contains the Effect Shader sample. This sample demonstrates Jupiter's use of the new EffectShader system.

NEW  The \Samples\debugging\stacktrace folder contains the StackTrace sample. This sample demonstrates Jupiter's use of the new Stacktrace library.

NEW  The \Samples\models\obb folder contains the ModelOBB sample. This sample demonstrates Jupiter's use of ray to ModelOBB collision detection.

NEW  The \Samples\graphics\bump folder contains the DOT3 Bump sample. This sample demonstrates Jupiter's use of DOT3 bump maps.

Tools:

NEW  The DTXOptimizer command line tool was added. This tool allows you to quickly optimize texture mipmaps and compression types. (make backups before you run this tool!)

NEW  Photoshop DTX Plug-in has been re-written.

Change List

Engine

  • New EffectShader system: native support for DirectX Effect files. (HLSL)
  • Fixed render model skeletal meshes not resetting pixel or vertex shaders.
  • Removed several DX8 work arounds which were causing problems with DX9 and fog.
  • Sound: changed 3D buffer calls to deffered instead of immediate reducing amount of potential remixes. (remix every 10ms )
  • Added the ability to use sprites as skins for the LTBModel effects
  • Fixed shadows not working properly which was introduced in version 68
  • Added access to the D3DDevice from game code, through GetEngineHook()
  • ILTFontManager::CreateFont now takes a pointer to an LTFontParams class from true type fonts which allows developer to control some of the LogFont parameters.
  • Allow model vertex/pixel shaders to regress to software when not supported. ( pixel/vertex shader support is < 1.0 )
  • Use the first renderpasses dynamic light on all passes console varible "MultiPassLightMatch" "0" ( turn off multipass light match by default)
  • Remove various potential sound system memory leaks
  • Reenable renderstyle specular highlights
  • Windowed mode was calculating window sizes incorrectly causing the final surface to render compressed by 1 pixel in x and y. ie 640x480 final render was compressed to 639x479.
  • Added console varibles to control filtering in 2doptimized mode. ( useful for pixel perfect interfaces ) 2Dbilinear - default is on and 2DAnisotropic - default is off  NOTE: when 2Danisotropic is on it takes precedent over 2Dbilinear
  • Engine now save render states after default states are set
  • Remove crash calling 0 if sound device doesn't exist on a machine. The application needs to handle the return value during InitSound()
  • Reimplemented text colors in the console display.
  • added CloseHandle() to directmusic thread shutdown - causing memory leak
  • memory allocations of zero bytes is now allocated as a valid pointer. This fixes several DirectX warnings and failures.
  • add to existing console error: ModelInstance::UpdateCachedTransforms failed for %s. "Possible missing weightset(s)" This could mean that a model has missing weightset for animations.
  • Fixed issue with DrawSurfaceMasked().
  • Wide character unicode support through ilttexturestring interface.
  • Fixed animation tracker out of sync reset issue when other tracker are updated.
  • Optimization: Updated packet class to do full memcpy copy instead of 32 bits at a time.
  • ModelOBB support fully re-enabled.
  • DOT3 Bump-map support using the fixed function pipeline.
  • Fixed GetVersionInfo and GetPerformanceInfo
  • Fixed DOS attack issue which caused network thread to exit, kicking all connected clients.

Libs

  • dtxmgr: Used for apps that need to manipulate DTX files easily.
  • ButeMgr: change save so exception isn't throwned causing destructors to be called when unloading object.lto
  • stacktrace: Added stacktrace library which provides an interface for runtime stack traces

Tools

  • FxED: Fixed the one time startup crash
  • WorldPacker: updated compiler optimizations for speed.
  • DEdit: modified error message when failed to load object.lto. Should give more info now.
  • DEdit: now passes the current project directory to winpacker.
  • DEdit: "Hollow" option is re-enabled. "Carve" option removed as it has been disabled for a while.
  • Don't allow Modeledit and Modelpacker to open world or renderstyles .lta's. These are not valid models and if they are opened with Modeledit etc it will crash.
  • ModelEdit: Fix Piece LOD generate so the LOD is viewable without saving and reloading the model
  • RenderStyle Editor:
    • Fix ColorOp and AlphaOp for editor and packer. Remove PS2 options.
    • Fix incorrect colorop drop down ( not all options were displayed )
    • Fix some ColorOp's not being written to the lta file.
    • Add in COLOROP_MODULATETEXTUREALPHA ALPHAOP_MODULATETEXTUREALPHA. These were added to the engine but not the packer or editor.
  • Plugins: Added support for Maya 6.5 & 7.0.
  • Plugins: Added support for Max 7.0.
  • Plugins: Max Model Exporter: Fixed 180 rotation problem.

ClientFX

  • LTBModel: can use sprite as skin now.
  • FX can use the new EffectShader system. (for applicable FX)

 Build 68

New Features

The Jupiter System now supports Visual C++ .NET 2003 (7.1). The Jupiter System still supports Visual C++ .NET 2002 (7.0). Visual C++ 6 is, however, no longer supported due to requirements for DirectX 9.

The Jupiter System engine, tools, and samples have been modified to use DirectX 9.

The Jupiter System now supports Maya 6.0.

The Jupiter System now supports DirectShow for video playback.

Support for Linux has been added to the Jupiter System server library.

Documentation:

UPDATED  The Jupiter Development Guide provides introductory, overview, and quickstart information for programmers and artists using the Jupiter System.

UPDATED  The Jupiter API Reference provides documentation for classes and functions.

NEW  The Collision Types in Jupiter whitepaper describes the different options for collision primitives in the Jupiter System.

NEW  The General Debugging 101 whitepaper contains some useful techniques for debugging the Jupiter System for PC. Many of the techniques described may be of use outside of the Jupiter System.

NEW  The Importing Custom LODs whitepaper explains how to import model LODs (level-of-detail) made in 3D Studio Max or Maya into ModelEdit.

NEW  The Linux Dedicated Server whitepaper explains how to build the Linux server library and dedicated server sample application.

NEW  The Renderer Visibility System whitepaper explains the details of the Jupiter occluder system.

Samples:

NEW  The \Samples\audio\music folder contains the Music sample. This sample demonstrates Jupiter's DirectMusic interface using music files from No One Lives Forever™ 2.

NEW  The \Samples\graphics\fonts\ folder contains the Fonts sample. This sample demonstrates the creation and display of vector (*.ttf) and bitmap (*.dtx) fonts.

UPDATED  The \Samples\graphics\shaders\ folder contains the Shaders sample. This sample demonstrates the use of vertex and pixel shaders on models using RenderStyles.

NEW  The \Samples\graphics\video folder contains the Video sample. This sample demonstrates the video playing functionality of Jupiter.

UPDATED  The \Samples\networking\sealhunter folder contains the Seal Hunter sample. This light humored sample implements a single player and networked multiplayer mini game with the following features:

  • Single player or multiplayer game (supports up to 12 players in multiplayer)
  • Windows and Linux stand-alone server for hosting games
  • Scoring system, current score HUD, and ranking screen

Change List

Changes That Affect Multiple Systems

  • Added support for Visual C++ .NET 2003 (7.1).
  • Removed all Visual C++ 6 projects and workspaces. Jupiter no longer supports Visual C++ 6, because of DirectX 9 requirements.
  • Modified Jupiter to use DirectX 9 interfaces.
  • Added support for Maya 6.0.
  • Added DirectShow video playback support.
  • Added Linux server support.

Engine

  • UI: Fixed bitmap font support.
  • Renderer: Fixed a SkyBox rendering error when rendering to multiple cameras.
  • Renderer: Disabled fogging of shadows.
  • Renderer: Modified renderer to use DirectX 9 interfaces.
  • Server: Fixed various issues in game_serialize.
  • Server: Added Linux server support.
  • ClientFX: Fixed a particle system crash for particle systems that use "FlipRenderingOrder".
  • Kernel: Added IHAVEPURCHASEDBINK define around Bink specific sections of code. Also added comments about how to enable it if someone was to purchase it.
  • Kernel: Add direct show video manager. Allows playing of avi and asf wmv ( non-drm ).
  • Client: Fixed bug in bilinear filtering in the console. Was being set to D3DTEXF_POINT regardless of the validity of the current filter.
  • sdk/inc: Added ltcrashhandler class for creating MINIDUMPs on application crash.

Libs

  • ButeMgr: Fixed crash in ButeMgr involving strstream.
  • zlib: Updated zlib to version 1.2.1.
  • stdlith: Added std::iostream interface to gzlib.
  • stdlith: Removed unused CompressedIO class.
  • STLport: Removed STLport library, because the Visual C++ .NET 2002 and 2003 projects use the Microsoft STL.

Tools

  • DtxShellEx: Added the DtxShellEx tool, which is a Windows Explorer extension for viewing DTX files.
  • DtxView: Added the DtxView tool, which can open a DTX file for viewing.
  • dtxutil: Modified dtxutil to include two new command line options: -dtxdirreport (Recursively report dtx file info in a directory tree) and -dtxdirdelim (Recursively report dtx file info to a comma delimited file).
  • DEdit: Added two new options to the Node View Menu: +Delete Empty Containers and +Delete Empty Container Cascade.
  • DEdit: Added more descriptive information for when an object.lto fails to load.
  • LithRez: Updated LithRez to allow multiple wildcards.
  • LithRez: Fixed ExtCheck() in LithRez to be case-insensitive.
  • 3D Studio Max Exporter: Fixed exporting of native Max boned animations.
  • RenderStylesEditor: Fixed a save error in the RenderStylesEditor. The vertex/pixel shader information was only getting saved if a vertex shader was used.
  • vcvars: Added tool that returns the correct vcvars.bat call given a variable. Ex. vcvars 6 return call "x\x\x\vcvars.bat". Available params are 6 2002 2003. Call from a batch file like this before building: call vcvars 6 > doit.bat
  • pscompiler: Removed the pscompiler tool. This tool is no longer valid. Use the DirectX 9 shader compilers instead.
  • Model_Packer: Fixed incorrect command line paramter passed to compiler.
  • Maya 6.0 Plugins: Added support for Maya 6.0.

Game (NOLF2 Code)

  • UI: Fixed memory leak in ltguibutton.

Samples

  • Fonts: Added new Font sample that displays True Type, proportional bitmap, and monospace bitmap fonts.
  • Music: Added new Music sample that demonstrates the DirectMusic interface in Jupiter.
  • Seal Hunter: Added PolyTrail effect to mallet.
  • Seal Hunter: Added dedicated server application for Windows and Linux.
  • Shaders: Update the Shaders sample to support DirectX 9 shaders. Added a toon shader and the ability to switch shaders.
  • Video: Added video playing sample application.

Change List

Engine

  • Fixed an engine crash caused by EnvBumpMap texture command strings.
  • Optimized the rendering of particle systems.
  • Added ModelLightingSkipRootNode console variable which allows the lighting consideration to use the root node's first child node position instead of the root node position. This is useful in cases where you have a model animation that translates very far from the root node (perhaps in a cut scene).
  • Added missing W values to lightmapped and gouraud shaders.
  • Changed default value of 32bittextures to 1.
  • Changed zbias values to fix an ATI problem with z-fighting for lightmapped surfaces.
  • Fixed memory leaks.

Tools

  • DEdit/FxEd: Changed splash screens for DEdit and FxEd.
  • WorldPacker: Fixed issue with the way ambient light is handled. Now when local and global amients are added together, the value is clamped at 255.

Game (NOLF2 Code)

  • Fixed upper body rendering error caused by tracked node control.

 Build 62

Game:

If you are using an earlier build of Jupiter, then due to changes in the game code you must reprocess all your models through ModelEdit after installing. Failure to reprocess your models will result in either incorrect model display, or failure of models to appear in the game.

To reprocess your model textures
1. Open the .LTA or .LTC model file to process.
2. On the File menu, click Save And Compile.
3. Specify the name of the .LTB file to replace, or type the name of the new .LTB file to create.
4. Click the Save button.
