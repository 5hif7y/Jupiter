 What's New?

Visual C++ .NET 2003

The Jupiter System now supports Visual C++ .NET 2003 (v7.1). Visual C++ .NET 2002 (v7) is no longer supported.

DirectX 9 Effect Files

The Jupiter System introduces the new EffectShader system for utilizing DirectX Effect files.

Maya 7.0

The Jupiter System now supports Maya 7.0.

DirectShow Video Playback

The Jupiter System now supports DirectShow for video playback.

Linux Server

Support for Linux has been added to the Jupiter System server library.

 Required Model/World Reprocessesing

If you are using Jupiter Build 68 or earlier, then due to changes in the system code you must reprocess all your models through ModelEdit after installing. Failure to reprocess your models will result in either incorrect model display, or failure of models to appear in the game. You must also reprocess your worlds. The world vertex format has changed to support tangent space used by the EffectShader system.

To reprocess your models:

  1. Open the .LTA or .LTC model file to process.
  2. On the File menu, click Save And Compile.
  3. Specify the name of the .LTB file to replace, or type the name of the new .LTB file to create.
  4. Click the Save button.

 Building from the Command Line

To build the engine from the command line:

  1. Open a DOS window.
  2. Switch to the \TouchdownEntertainment\Jupiter_Ent\Engine\Runtime\ directory.
  3. Run the build.bat file for Visual Studio .NET 2003 (v7.1).
  4. Open the build.log file to view the output.

You can also open the build.bat file from an explorer window, but you won't be able to review the output after the build process has completed.

To build the engine tools from the command line:

  1. Open a DOS window.
  2. Switch to the \TouchdownEntertainment\Jupiter_Ent\Engine\Tools\ directory.
  3. Run the build.bat file for Visual Studio .NET 2003 (v7.1).
  4. Open the build.log file to view the output.

In order for the exporter plugins to build, you will need to copy over the Max and/or Maya SDK files. See the readme files in the \Engine\Tools\Plugins\ sub-folders for more information.

To build the samples from the command line:

  1. Open a DOS window.
  2. Switch to the \TouchdownEntertainment\Jupiter_Ent\Samples\ directory.
  3. Run the build.bat file for Visual Studio .NET 2003 (v7.1).
  4. Open the build.log file to view the output.

To build the No One Lives Forever™ 2 game code from the command line:

  1. Open a DOS window.
  2. Switch to the \TouchdownEntertainment\Jupiter_Ent\Game\ directory.
  3. Run the build.bat file for Visual Studio .NET 2003 (v7.1).
  4. Open the build.log file to view the output.

 Building from Visual Studio

Visual Studio .NET 2003 (v7.1) Instructions:

To build the engine code from Visual Studio .NET 2003 (v7.1):
  1. Right click on the \TouchdownEntertainment\Jupiter_Ent\Engine\Runtime\Engine.sln file and select Open With Visual Studio .NET 2003 ( you may also double click on the sln file ).
  2. If any Source Control dialogs appear, click No or Cancel to dismiss them.
  3. Select Rebuild Solution from the Build menu.
To build the engine tools code from Visual Studio .NET 2003 (v7.1):
  1. Right click on the \TouchdownEntertainment\Jupiter_Ent\Engine\Tools\Tools.sln file and select Open With Visual Studio .NET 2003 ( you may also double click on the sln file ).
  2. If any Source Control dialogs appear, click No or Cancel to dismiss them.
  3. Select Rebuild Solution from the Build menu.
To build the samples from Visual Studio .NET 2003 (v7.1):
  1. Right click on the project solution file (*.SLN) in the sample folder (Ex. \TouchdownEntertainment\Jupiter_Ent\Samples\base\samplebase\samplebase.sln) and select Open With Visual Studio .NET 2003 ( you may also double click on the sln file ).
  2. If any Source Control dialogs appear, click No or Cancel to dismiss them.
  3. Select Rebuild Solution from the Build menu.
To build the No One Lives Forever™ 2 game code from Visual Studio .NET 2003 (v7.1):
  1. Right click on the \TouchdownEntertainment\Jupiter_Ent\Game\TO2.sln file and select Open With Visual Studio .NET 2003 ( you may also double click on the sln file ).
  2. If any Source Control dialogs appear, click No or Cancel to dismiss them.
  3. Select Rebuild Solution from the Build menu.

 Debugging the Samples

To debug the samples from Visual Studio .NET 2003 (v7.1):

To debug the samples using Visual Studio .NET 2003 (v7.1), follow the instructions in the previous section to build the engine. Next, run copy_binaries.bat in the \TouchdownEntertainment\Jupiter_Ent\Samples\bin folder. In Visual Studio .NET 2003, open the project properties for cshell and click the Debugging section and enter the following parameters:

Command:

Enter the path and filename for the lithtech executable: \TouchdownEntertainment\Jupiter_Ent\Samples\bin\debug\lithtech.exe

Command Arguments:

Enter the following text:

-rez engine.rez -rez ..\..\sample_type\sample_dir\rez -config ..\..\sample_type\sample_dir\bin\autoexec.cfg

Note that "sample_type\sample_dir" is the directory where the sample exists. For example, the command arguments for the SampleBase sample would be:

-rez engine.rez -rez ..\..\base\samplebase\rez -config ..\..\base\samplebase\bin\autoexec.cfg

Working Directory:

Enter the path to the Samples bin\debug directory: \TouchdownEntertainment\Jupiter_Ent\Samples\bin\debug

 Debugging No One Lives Forever™ 2

To debug No One Lives Forever™ 2 from Visual Studio .NET 2003 (v7.1):

To debug the samples using Visual Studio .NET 2003 (v7.1), follow the instructions in the previous section to build the engine and No One Lives Forever™ 2. Open the solution TouchdownEntertainment\Jupiter_Ent\Game\T02.sln in Visual Studio .NET 2003. Open the project properties for ClientShellDLL and click the Debugging section and enter the following parameters:

Command:

Enter the path and filename for the lithtech executable: \TouchdownEntertainment\Jupiter_Ent\Development\TO2\Lithtech.exe

Command Arguments:

Enter the following text:

-windowtitle "No One Lives Forever 2" -rez GAME +multiplayer 0 +DisableMusic 0 +DisableSound 0 +DisableTripBuf 0 +DisableHardwareCursor 0 +DisableHardwareSound 0 +DisableSoundFilters 0 +Windowed 1 +DebugLevel 1

Working Directory:

Enter the path to the No One Lives Forever™ 2 directory: \TouchdownEntertainment\Jupiter_Ent\Development\TO2

Launching the Game Within DEdit

To launch No One Lives Forever™ 2 from DEdit:

  1. Run DEdit.
  2. Select Edit and then Options.
  3. Select the Run tab.
  4. Enter the following parameters:

    Executable:

    Enter the path and filename for the lithtech executable: C:\TouchdownEntertainment\Jupiter_Ent\Development\TO2\Lithtech.exe

    Working directory:

    Enter the path to the root of the NOLF2 game directory: C:\TouchdownEntertainment\Jupiter_Ent\Development\TO2

    Program arguments:

    Enter the following text: -rez engine.rez -rez ..\..\Game +runworld %WorldName%

  5. Select OK.
  6. When you have a world open, you can now click the Run World button to launch the game.

To launch a sample from DEdit:

  1. Run DEdit.
  2. Select Edit and then Options.
  3. Select the Run tab.
  4. Enter the following parameters:

    Executable:

    Enter the path and filename for the lithtech executable: C:\TouchdownEntertainment\Samples\bin\Release\Lithtech.exe

    Working directory:

    Enter the path to the lithtech executable: C:\TouchdownEntertainment\Samples\bin\Release

    Program arguments:

    Enter the following text:

    -rez engine.rez -rez ..\..\sample_type\sample_dir\rez -config ..\..\sample_type\sample_dir\bin\autoexec.cfg +runworld %WorldName%

    Note that "sample_type\sample_dir" is the directory where the sample exists. For example, the program arguments for the SampleBase sample would be:

    -rez engine.rez -rez ..\..\base\samplebase\rez -config ..\..\base\samplebase\bin\autoexec.cfg +runworld %WorldName%

  5. Select OK.
  6. When you have a world open, you can now click the Run World button to launch the game.
